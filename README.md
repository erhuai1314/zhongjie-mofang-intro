## 这是什么

**中介魔方（统计数据生成工坊）** 解决的是一个常被忽视的问题：**还没有数据时，怎么练统计、怎么验证研究设计？**

SPSS、R、Mplus 解决的是「数据来了怎么分析」；中介魔方解决的是这个环节**之前**的事——按你的理论参数（路径系数、样本量、效应量）生成高质量仿真数据，并自动完成信效度验证与统计检验。

三种典型用途：

1. **方法学习与练手**——想学中介效应、LCA、SEM，但没有现成数据
2. **研究设计预测试**——正式收集数据前，先用模拟数据试跑整个分析流程，检验样本量与效应量假设是否成立
3. **教学演示**——课堂或组会上现场生成数据、现场跑模型，比截图讲义直观得多

## 核心特性

- **自定义模拟**：样本量、路径系数、效应量均可设定，一键生成 CSV 数据
- **自动信效度验证**：Cronbach's α、AVE、CR、Fornell-Larcker 区分效度
- **结构模型指标**：CFI、TLI、RMSEA 等拟合指标自动输出
- **功效分析内置**：蒙特卡洛法估算中介效应等模型所需样本量
- **手机端即开即用**：微信小程序，无需安装、无需注册、无需写代码

## 快速开始

1. 微信内搜索小程序「中介魔方」
2. 选择模型类别与具体模型，填入理论参数（有默认值可参考）
3. 生成模拟数据 → 查看信效度与统计检验结果 → 导出 CSV（导出需分享解锁）

## 适合谁 / 不适合谁

**适合**：写论文前想练手的研究生、需要课堂演示的教师、做研究设计预测试的定量研究者。

**不适合 / 能力边界（重要）**：

- ⚠️ 生成的是**模拟数据**，不能作为真实调查结果写进论文或正式发表——这是这类工具的边界，不是缺点
- 不支持导入自有数据做分析——它是数据**生成**工具，不是 SPSS/R/Mplus 的替代品
- 数据导出需分享小程序解锁；免费使用，含插屏广告

## 与专业统计软件的关系

| | 中介魔方 | SPSS+PROCESS / R / Mplus |
|---|---|---|
| 定位 | 还没数据时：生成数据、练手、预测试 | 有数据后：正式分析与检验 |
| 成本 | 免费 | SPSS/Mplus 商业授权，R 免费但需写代码 |
| 平台 | 微信小程序（手机） | 桌面端 |

正式研究的最终分析仍应使用专业统计软件完成；中介魔方负责那之前的练习与设计验证环节。
